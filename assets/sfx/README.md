# SFX-банк Boomerang Knife (задача B2)

Полный набор коротких звуковых эффектов для аркады «Boomerang Knife».
Стиль: уютная «лесная ночь» фэнтези + неоновые ножи (золото/неон/лёд/рубин).
Звуки короткие, «сочные», без музыки, без клиппинга, без «страшилок».

## Формат

| Параметр | Значение |
|---|---|
| Контейнер / кодек | OGG Vorbis (`libvorbis`, q=4) |
| Частота | 44100 Гц |
| Каналы | mono |
| Длительность | 0.06–0.65 с |
| Громкость | RMS −19.6…−15.8 дБ (нормализация к ≈ −16 дБ), пик ≤ −1.2 дБFS |
| Генерация | чистый ffmpeg-синтез (`aevalsrc`: синусы + chirp + `random()`-шум, сигмоидные «ворота», фильтры highpass/lowpass/afade), без внешних сэмплов |

Короткие файлы (<0.4 с) не имеют валидного интегрального LUFS по EBU R128
(интегральное окно ≥400 мс), поэтому для них действует альтернативный критерий
ТЗ — RMS −20…−14 дБ; все файлы в диапазоне.

## Как подключить (для B3)

Файлы готовы к использованию как `AudioStreamOggVorbis` — заменить процедурные
`_build()` в `scripts/audio_manager.gd` на прелоад:

```gdscript
# пример: вместо AudioManager.play("hit") ничего менять не нужно,
# если в _build подставить файл:
var stream: AudioStreamOggVorbis = load("res://assets/sfx/hit.ogg")
_build("hit", stream)
```

Имена событий из таблицы выше совпадают со строками, которые уже передаются в
`AudioManager.play(...)` в коде (`hit`, `break`, `return`, `click`, `level`,
`over`), плюс новые (`throw`, `hit_crit`, `catch`, `hover`, `buy`, `coin`,
`crystal`, `achievement`, `revive`, `win`, `defeat`, `shield`, `magnet`,
`combo`, `deny`, `daily`, `portal`) — останется только добавить их в словарь
плееров и вызвать в нужных местах.
