# Boomerang Knife — Музыкальные спеки (B1)

Композитор: music-composer subagent.
Формат: OGG Vorbis, 44.1 кГц, стерео, нормализовано ~-14 LUFS, бесшовный луп.

---

## 1. `memu_loop.ogg` — Главное меню («ночной лес»)

- **Длительность:** 35.56 c  |  **Файл:** 619208 байт (0.59 МБ)
- **BPM:** 108 (спокойный)  |  **Длительность в тактах:** 16 тактов 4/4 = 64 бита
- **Тональность:** A minor (ля минор, с теплотой — светлый минор)
- **Прогрессия (по 2 такта на аккорд):** `Am — F — C — G` (vi-IV-I-V по C)
    → классическая «уютная» фэнтези-пульсация без мрачности.
- **Настроение:** спокойное, уютное, ночной лес — мягкие пады, редкая флейтовая тема.

### Структура (16 тактов, луп)
| Такты | Что происходит | Характер |
|-------|----------------|----------|
| 1–4   | Пад + бас + арпеджио, тема вступает | Ровно, дышит |
| 5–8   | Флейтовая тема развивается, арпеджио мельче | Тепло, нарастает |
| 9–12  | Все слои, тема на октаву выше | Кульминация «рощи» |
| 13–16 | Спад к тишине, хвост в луп | Возврат к началу (анахруз) |

### Инструментовка (синтез)
- Мягкий saw-пад (сочный, low-pass ~40%) — аккорды целиком по такту.
- Треугольный бас по корням.
- Плук-арпеджио (soft square, low-pass) — восьмые, рисует гармонию.
- Флейтоподобная синус-тема «мотива ночи» — редко, по 1-й/3-й доле.

## 2. `gameplay_loop.ogg` — Классика / Бесконечный

- **Длительность:** 30.48 c  |  **Файл:** 630497 байт (0.60 МБ)
- **BPM:** 126 (энергичная аркада)  |  **Тактов:** 16 тактов 4/4 = 64 бита
- **Тональность:** C major (до мажор, яркая, семейная)
- **Прогрессия (по 4 такта на аккорд):** `C — G — Am — F` (I-V-vi-IV)
    → самый «драйвовый» и знакомый рок/поп ход; драйв без агрессии.
- **Настроение:** энергично, чисто, позитивно. Напор без злобы — под семейный рейтинг.

### Структура (16 тактов, луп)
| Такты | Что происходит |
|-------|----------------|
| 1–4   | Kick+hat+snare, бас-пульс, стаккато-арпеджио (C) |
| 5–8   | Удар аккордом G — динамика выше |
| 9–12  | Амбиэнс Am — лёгкое дыхание |
| 13–16 | F-разгон, плотный финал в луп |

### Инструментовка (синтез)
- Ударные: kick (синус-spweep), hat-восьмые (шум), snare на 2/4 (шум+тело).
- Saw-бас — пульс восьмыми по корням с октавным смещением.
- Яркий square-лид — 16-е арпеджио по тонам аккорда.
- Лёгкая реверберация на перкуссии (~15%).

## 3. `duel_loop.ogg` — Дуэль

- **Длительность:** 20.87 c  |  **Файл:** 503429 байт (0.48 МБ)
- **BPM:** 138 (напряжённый)  |  **Тактов:** 12 тактов 4/4 = 48 бит
- **Тональность:** E minor + B (натуральный минор с острым лидом — тревога без злобы)
- **Прогрессия (по 3 такта):** `Em — G — Am — B` (i-III-iv-V)
    → минорная напряжённость, «ой-ой-ой как близко», но не злая.
- **Настроение:** напряжённо, «ходы и удары», пульс боя. Семейно допустимо.

### Структура (12 тактов, луп)
| Такты | Что происходит |
|-------|----------------|
| 1–3   | Пульсующий бас, стаккато-стабы аккордов (Em) |
| 4–6   | Триольное напряжение G, шире |
| 7–9   | Am — «затишье перед ударом» |
| 10–12 | Всплеск на B, хвост в луп (перехват ритма) |

### Инструментовка (синтез)
- Saw-бас — пульс восьмыми (острые атаки).
- Стаккато-square-стабы аккордов на 1/3 долях (триады).
- Снар «удары/ходы» на 2/4 + редкий акцент.
- Высокое sine-остинато (тремоло) для тревожного фонового звона.

## Технические заметки
- **Seamless:** каждый трек композиционно лайкован по целому числу тактов; после нормализации применена финальная кросс-фейд-склейка 12 мс на стыке — голова и хвост окна совпадают (mean diff < 0.005), кликов на луп-точке нет.
- **Громкость:** ebur128: memu -14.1 LUFS, gameplay -15.4 LUFS, duel -14.1 LUFS; true peak -2.7… -3.5 dBFS (клиппинга нет).
- **Звук не прослушивался на слух** — верифицирован измерениями (ffmpeg ebur128 + анализ стыка в Python).

## Уровень качества
- **Качество:** ДЕМО высокого уровня (полноценная синтезированная аранжировка, живые-яровые лупы, готовая громкость).
- **Что не хватает до «боевой записи»:** живые/сэмплированные инструменты с реальными тембрами, профессиональный мастеринг, человека-композитора для финального художественного контроля и масс-мейстеринга под общий микс игры. Это синтез «с нуля» — хорош как играемый саундтрек, но не студийная запись.
- **Импорт в Godot:** files → перетащить `*.ogg` / AudioStreamPlayer → Stream. (Звук, как обычно, ПОСЛУШАТЬ пользователю перед окончательным выбором.)
