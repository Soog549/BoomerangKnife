# BoomerangKnife (Нож Бумеранг) — студия ZWS

Казуальная аркада: бросай бумеранг‑нож, отражай волны, ставь рекорды.
Godot 4.7.2 · портрет 720×1280 · web + Android · 10 языков · RELEASE‑GATE 11/11.

## Как запустить за 5 минут
1. Открой проект в **Godot 4.7.2** (или выше 4.4): `project.godot`.
2. Жми **F5** (или Run) — откроется главное меню.
3. **Web:** `python -m http.server 8090 --directory build/web` → открой `http://127.0.0.1:8090/`.
4. **Android:** `build/android/boomerangknife.apk` (56.3 МБ, подписан).
5. Сборка заново: `build_web.bat` / `build_android.bat`.

## Режимы
- **Классика** — Knife Hit‑ядро (цель с секторами).
- **Бесконечный** — волны, рекорды.
- **Дуэль** — против бота.
- **Арена мобов** — уклонение, щит, лут (4 редкости), комбо, боссы.
- **TD‑прото** — 3 карты, 3 башни ×3 уровня, боссы (тренажёр для спин‑оффа).
- **Коллекция** — 12 карточек за реликвии · **МОЯ ИГРА** — персонализация.

## Кейсы (проблема → решение → метрики → артефакты → ссылка)
1. **Портрет‑игра в web‑окне обрезалась** → CSS transform scale (FITV5) + `aspect=keep` → вписывается целиком, адаптив в реальном времени → `web/yandex_sdk.js`.
2. **Краш `Lambda capture freed`** → `is_instance_valid()` в лямбдах меню/игры → старт стабилен → `scripts/main_menu.gd`, `scripts/main.gd`.
3. **PCK 44→32 МБ** → музыка WAV→OGG (15→1.9 МБ) + вынос неиспользуемых ассетов → быстрее загрузка → `assets/audio/music12`, `tools/gen-*`.

## Стек/структура
- `scripts/` — логика (GameState, AudioManager, AdService, L10N, main_menu, mob_arena, td, collection…).
- `scenes/` — сцены. `assets/` — арт/звук/аватары/щиты/карточки.
- `locale/translations.csv` — 10 языков (ru/en/uk/es/de/fr/pt/it/pl/tr).
- `web/yandex_sdk.js` — Yandex SDK: i18n на старте, LoadingAPI, реклама.
